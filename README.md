# Reproduction Package: Fluctuation scaling in agricultural commodity markets
This repository contains the data and code required to reproduce the empirical findings and figures presented in the Brief Report: **"Fluctuation scaling in agricultural commodity markets"** by Benjamin Schiek (PNAS Nexus, 2026).
## Contents
-The raw agricultural commodity data files in compressed format (.7z).
-The R script file (.R) used to import, process, and analyze the raw data, and to generate Figures 1 and 2 appearing in the Brief Report.
## Instructions for Reproduction
1. **Software Requirements:** Analysis was performed in R (v4.2.1) using the `tidyverse` and `patchwork` packages. (Note that `ggplot2` is included in `tidyverse`.)
2. **Execution:** - Unzip the data files. Put the unzipped .csv and .xlsx files in your data folder. Run the R script (reproductionCode.R).
## Data Sources
See references in the Brief Report. Links to the websites where the data was downloaded for this study are included in the R script, but these links will not be updated if they decay.
